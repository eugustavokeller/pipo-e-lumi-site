Política de privacidade

Última atualização: 17 de novembro de 2026

Resumo: este site não coleta nenhum dado. O canal Pipo e Lumi não pede, não recebe e não guarda dados pessoais de crianças. A ferramenta interna que publica os vídeos acessa apenas o próprio canal, com a autorização do dono.

Quem somos

Pipo e Lumi é um canal do YouTube com canções originais em desenho animado para crianças de 2 a 5 anos. Este site apresenta o canal para pais e responsáveis. Contato: gustavo.lealtec@gmail.com.

Este site

  • Não usa cookies, ferramentas de análise (analytics), pixels de anúncio nem rastreadores.
  • Não tem formulários, cadastro, login nem comentários.
  • É hospedado no GitHub Pages, que pode registrar dados técnicos de acesso (como o endereço IP) para segurança e funcionamento do serviço, conforme a declaração de privacidade do GitHub. Nós não temos acesso a esses registros.

Crianças

O conteúdo é feito para crianças, mas nenhuma parte do canal ou deste site pede informações de crianças. Os vídeos são marcados no YouTube como feitos para crianças; com isso, o próprio YouTube desativa comentários, notificações e anúncios personalizados nesses vídeos. Se uma criança enviar algum dado pessoal por e-mail, ele será apagado assim que percebido. Pais e responsáveis podem pedir a remoção de qualquer informação pelo e-mail de contato.

YouTube

Ao assistir aos vídeos no YouTube ou no YouTube Kids, valem os Termos de Serviço do YouTube e a Política de Privacidade do Google. Nós não recebemos dados pessoais dos espectadores; vemos apenas estatísticas agregadas e anônimas que o YouTube mostra a todos os criadores (por exemplo, número de visualizações).

Ferramenta interna de publicação

O canal usa uma ferramenta própria, de uso exclusivo do dono do canal, que envia os vídeos produzidos ao YouTube. Ela não é oferecida ao público e não tem outros usuários.

  • Dados acessados: com a autorização do dono do canal (login do Google), a ferramenta usa a YouTube Data API para enviar vídeos ao próprio canal, definir título, descrição, tags, idioma, legendas, miniatura, a marcação "feito para crianças" e a divulgação de conteúdo sintético, e consultar se esses vídeos já foram publicados.
  • Armazenamento: o token de acesso fica guardado apenas no servidor privado do dono do canal, com acesso restrito. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade. A ferramenta não acessa dados de espectadores, inscritos ou de outros canais.
  • APIs do Google: o uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.
  • Revogar o acesso: a autorização pode ser revogada a qualquer momento em myaccount.google.com/permissions. Os dados guardados podem ser apagados mediante pedido pelo e-mail de contato.
